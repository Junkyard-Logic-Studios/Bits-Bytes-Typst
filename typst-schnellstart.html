Typst-Schnellstart

Typst und VS Code einrichten und den ersten Bericht oder Foliensatz mit der TUBAF-Vorlage als PDF erstellen.

1. Typst, Git und VS Code installieren

Was möchtest du installieren?

Wähle mindestens ein Programm aus.

Windows · PowerShell 
winget install --id Typst.Typst --exact
winget install --id Git.Git --exact
winget install --id Microsoft.VisualStudioCode --exact

Führe die Befehle in PowerShell aus und öffne PowerShell danach neu.

macOS · Terminal mit Homebrew 
brew install typst
brew install git
brew install --cask visual-studio-code

Falls brew fehlt, folge zuerst der Homebrew-Anleitung.

Linux · Ubuntu mit Snap 
sudo snap install typst
sudo apt update
sudo apt install git
sudo snap install --classic code

Andere Distributionen: Typst, Git und VS Code bieten weitere Installationswege.

2. Tinymist in VS Code installieren

code --install-extension myriad-dreamin.tinymist

Falls code fehlt, öffne VS Code und installiere Tinymist Typst über die Erweiterungsansicht. Auf dem Mac kannst du den Terminal-Befehl über die Befehlspalette mit Shell Command: Install 'code' … in PATH aktivieren.

3. TUBAF-Vorlage klonen und ausprobieren

Wechsle im Terminal in den Ordner, in dem dein Projekt liegen soll.

git clone https://github.com/DM-3/TUBAF_typst_template.git
cd TUBAF_typst_template
code .
  1. Öffne example-report.typ für einen Bericht oder example-presentation.typ für Folien. Wenn code . fehlt, öffne den Ordner über Datei → Ordner öffnen.
  2. Öffne die Befehlspalette mit Strg+Umschalt+P (macOS ⌘+⇧+P) und suche nach Typst Preview:, um die Live-Vorschau zu starten.
  3. Ändere oben im #show-Block Titel und Namen. Schreibe unter der ersten Überschrift deinen eigenen Text. Lass die Beispieldatei, tubaf_template.typ und den Ordner logos zusammen.

Für das PDF führe im geklonten Ordner den passenden Befehl aus.

typst compile example-report.typ bericht.pdf
typst compile example-presentation.typ folien.pdf

Beim ersten Kompilieren braucht Typst Internet für die Pakete. Die Vorlage ist inoffiziell. Gleiche sie für Abgaben mit den Vorgaben deines Instituts ab.
